# 💰 FitTrack – Personal Finance Tracker

A modern Android application developed using **Kotlin** that helps users efficiently manage their personal finances by tracking income, expenses, and transaction history. FitTrack provides an intuitive interface for monitoring financial activities and maintaining better control over daily spending.

---

# 📖 Project Overview

**FitTrack** is a mobile finance management application designed to simplify personal budgeting. The application allows users to record income and expenses, categorize transactions, review financial history, and manage their financial information through a clean and user-friendly interface.

The project is developed using modern Android development practices and follows a structured architecture for better maintainability and scalability.
